## 快速上手

### 如何安装并启动这款软件？

桌面端：在下载页选择对应平台安装包，Windows 双击 .exe 安装、macOS 拖拽 .dmg、Linux 赋予执行权限后运行 .AppImage。启动后客户端会自动连接后台服务（默认 http://localhost:4178）并拉取系统配置；未登录也可浏览资源库，登录后可同步个人配置。

### 首次使用需要配置 API Key 吗？

需要。要真正调用模型生成内容，需在「资源库」中找到对应供应商并填写你自己的 API Key。未配置 Key 时仍可浏览模型信息，但无法发起生成任务。

## API 密钥与配置

### 在哪里填写 API Key？

打开「资源库」功能，找到对应供应商，点击填写密钥即可。未登录时密钥仅保存在本地；登录后可按当前账号同步到后台，其他用户无法查看你的密钥。

### 如何添加自己的供应商或模型？

在「资源库」页点击「添加」，可新增自定义供应商或自定义模型。自定义资源仅保存在本地，不上传服务器，会与系统自带资源一起展示和搜索。

## 功能使用

### 「模型推荐助手」是做什么的？怎么用？

点击主面板右上角的星标按钮即可打开，弹窗侧栏的「模型推荐」就是该功能。它会通过几个分层问题了解你的用途（叙事、角色一致性、镜头控制、效率等），最后用投票算法为你推荐最合适的视频模型。

### 视频生成支持哪些参数？

支持设置分辨率（720P / 1080P）、宽高比（16:9、9:16、1:1、4:3、3:4）、时长（2s–30s），以及自动匹配的优先级（清晰度 / 速度 / 价格优先）。

### 如何查看我生成过的任务记录？

每次生成都会写入后台任务记录（含生成模式、分辨率、时长、状态等）。登录后可在任务记录列表查看自己的历史任务。

## 常见问题

### 提示「无法连接后台服务」怎么办？

一般是后台服务未启动或端口不对。请先在 server 目录执行 npm run dev 启动后端（默认端口 4178），再启动客户端。

### 自定义供应商 / 模型的数据存在哪里？会同步到服务器吗？

只保存在本地 localStorage（键名 stunning-fast-store，字段 customProviders / customModels），不会写入后台数据库。换设备请使用「导出 / 导入」功能迁移。

### 如何把自定义资源迁移到另一台设备？

在「资源库」页点击「导出」生成 JSON 文件，在新设备上点击「导入」选择该文件即可。同 id 的资源会被覆盖。
