# 服务器配置建议

本页给出部署「绝色」整套服务（后端 API + 管理后台 + 数据库 + 官网/下载分发）的硬件选型建议，按用户规模分档，可直接照搬下单。

::: tip 架构原则
**应用服务器**扛计算与数据库，**OSS + CDN** 扛下载与静态资源带宽，两者解耦后可独立扩容。下载洪峰绝不冲击业务接口。
:::

## 一、分档速查

| 规模 | 应用服务器 | 数据库 | OSS+CDN | 月成本（估） |
| --- | --- | --- | --- | --- |
| 个人 / 内测（≤ 50 人） | 2C4G / 60G SSD | 与应用同机 MySQL | OSS 免费额度 + CDN | ¥80 ~ ¥200 |
| 标准生产（≤ 1000 人） | 4C8G / 100G SSD | 与应用同机 MySQL | OSS + CDN 按量 | ¥250 ~ ¥600 |
| 中大规模（≥ 5000 人） | 8C16G ×2 + SLB | 独立 MySQL 主从 | OSS + CDN 高配 | ¥1200 ~ ¥3000 |

::: warning 同机数据库的边界
前两档把 MySQL 装在应用服务器同机，省成本。当并发连接数持续 > 200 或单表数据 > 500 万行时，应拆出独立数据库实例。
:::

## 二、应用服务器规格

| 项目 | 标准生产（推荐） | 最小起步 | 大规模 |
| --- | --- | --- | --- |
| vCPU | 4 | 2 | 8（×2 节点 + 负载均衡） |
| 内存 | 8G | 4G | 16G |
| 系统盘 | 100G SSD | 60G SSD | 100G SSD |
| 数据盘 | 80G SSD（挂 `/data`，MySQL 数据目录） | 与系统盘共用 | 200G SSD |
| 公网带宽 | 5 Mbps | 3 Mbps | 10 Mbps + CDN 兜底 |
| 系统 | Ubuntu 22.04 LTS / Debian 12 | 同左 | 同左 |
| 进程守护 | pm2 | pm2 | pm2 + 多实例 |

::: info 带宽为何只要 5 Mbps
应用服务器只跑 API（请求小、响应快），下载流量全部走 CDN。5 Mbps 足够支撑千级日活的 API 调用；带宽瓶颈由 CDN 承接。
:::

## 三、OSS + CDN 配置

### 3.1 对象存储（OSS）

| 项 | 建议 |
| --- | --- |
| 选型 | 阿里云 OSS / 腾讯云 COS / Cloudflare R2（出站免费，海外优先） |
| 桶名 | `juese-assets` |
| 桶结构 | `releases/`（安装包 + `latest*.yml`）、根目录（VitePress 官网产物） |
| 存储费 | ¥0.12 / GB / 月（安装包约 80MB × N 版本，可忽略） |
| 读写 | 内网回源免流量费，公网下载走 CDN |

### 3.2 CDN

| 项 | 建议 |
| --- | --- |
| 加速域名 | `cdn.juese.app` |
| 回源 | OSS 桶 |
| 加速类型 | 静态网页 + 大文件下载 |
| 缓存策略 | `releases/*` 缓存 7 天；`*.html` 缓存 5 分钟；`assets/*` 缓存 30 天 |
| 流量预估 | 单安装包 ~80MB，1000 次下载 ≈ 80GB；按 ¥0.2/GB ≈ ¥16 |

::: tip 成本大头是下载流量
存储费几乎可忽略，CDN 流量费是可变成本主项。用 Cloudflare R2 可免出站流量费，国内用户可选阿里云/腾讯云 CDN 走大陆节点。
:::

## 四、数据库（MySQL 8.x）规格

| 项 | 标准生产 | 大规模 |
| --- | --- | --- |
| 实例 | 与应用同机 | 独立实例（主从） |
| 规格 | 4C8G 共享 | 4C8G 专属 ×2（主从） |
| 磁盘 | 80G SSD | 200G SSD + 独立备份盘 |
| 连接池 | 应用端 `connectionLimit=10` | `connectionLimit=20` ×2 应用 |
| 字符集 | `utf8mb4` + `utf8mb4_unicode_ci` | 同左 |
| 备份 | 每日 `mysqldump` 到 `/data/backup/`，保留 14 天 | 每日全量 + binlog 增量，归档到 OSS |

::: warning 自动建表
启动后端服务时 `schema.ts` 会执行 `CREATE TABLE IF NOT EXISTS`（幂等），**无需手动建表**。本仓库另提供独立脚本 `server/sql/init.sql` 供预建库表使用。
:::

## 五、域名与证书

| 域名 | 类型 | 指向 | 用途 |
| --- | --- | --- | --- |
| `juese.app` | A / CNAME | OSS 静态托管 / CDN | 官网入口 |
| `cdn.juese.app` | CNAME | CDN | 安装包、更新清单、官网静态资源 |
| `api.juese.app` | A | 应用服务器公网 IP | API + 管理后台 |
| `docs.juese.app`（可选） | CNAME | CDN | 文档站独立子域 |

- HTTPS：Let's Encrypt 免费证书，`certbot --nginx` 自动续期。
- 三个域名解析独立，便于流量拆分与故障隔离。

## 六、月度成本估算（标准生产档）

| 项 | 规格 | 月成本（估） |
| --- | --- | --- |
| 应用服务器 | 4C8G / 100G SSD / 5Mbps | ¥200 ~ ¥350 |
| OSS 存储 | ~5GB | ¥1 |
| CDN 流量 | ~50GB（约 600 次下载） | ¥10 ~ ¥30 |
| 域名 | 摊销 | ¥5 |
| HTTPS | Let's Encrypt | ¥0 |
| **合计** | | **¥220 ~ ¥390** |

::: tip 降本路径
- 用 Cloudflare R2 替代国内 OSS，下载流量费归零。
- 应用服务器选包年包月（较按量省 30%~50%）。
- 内测期用 2C4G 起步，监控 CPU > 70% 再升配。
:::

## 七、选型决策树

1. **用户 < 50，预算敏感** → 2C4G 应用服务器 + OSS 免费额度 + Cloudflare R2（出站免费）。
2. **用户 < 1000，国内为主** → 4C8G 应用服务器 + 阿里云 OSS+CDN（同机 MySQL）。
3. **用户 > 5000，或对可用性有要求** → 8C16G ×2 + SLB + 独立 MySQL 主从 + CDN 高配。

::: info 上线后扩容信号
- 应用服务器 CPU 持续 > 70% → 升配或加节点。
- API 响应 P95 > 500ms → 查慢查询、加索引或拆数据库。
- CDN 流量月增 > 30% → 确认是否异常下载，必要时升 CDN 套餐。
:::
