# 安装指南

欢迎使用绝色！本页将帮助你快速安装并启动软件。

## 支持平台

| 平台 | 格式 | 说明 |
| --- | --- | --- |
| Windows | .exe 在线安装器 | 约 2 MB，运行后自动下载完整程序（约 80 MB） |
| macOS | .dmg | Intel / Apple Silicon 通用安装包 |
| Linux | .AppImage | 免安装，赋予执行权限后直接运行 |

## 下载安装

1. 前往 [下载页](/download) 选择对应平台的安装包。
2. 按下面步骤安装：

### Windows

双击下载的 .exe 在线安装器，它会自动从 CDN 拉取完整程序并安装。安装完成后从开始菜单启动「绝色」。

> 💡 在线安装器需要联网。如需离线完整包，请在下载页查看可选方案。

### macOS

打开 .dmg 文件，将「绝色」图标拖入「应用程序」文件夹。首次启动时若提示「未验证的开发者」，前往 **系统设置 → 隐私与安全性**，点击「仍要打开」即可。

### Linux

```bash
chmod +x 绝色-*.AppImage
./绝色-*.AppImage
```

## 首次启动

启动后客户端会自动连接后台服务并拉取系统配置。

- **连接成功**：展示完整资源库，登录后可同步个人配置与 API Key。
- **后台不可达**：会回退到内置默认配置，UI 仍可浏览，但无法登录与同步。

## 配置 API Key

要真正调用模型生成内容，需要在「资源库」中找到对应供应商（如通义万相、可灵、Runway 等），填写你自己的 API Key。

未配置 Key 时仍可浏览模型信息，但无法发起生成任务。

::: tip 密钥安全
- 未登录时密钥仅保存在你本机（localStorage），不会上传服务器。
- 登录后可按账号同步到后台加密存储，其他用户无法查看你的密钥。
- 换设备请使用「导出 / 导入」功能迁移密钥与自定义资源。
:::

## 自动更新

客户端内置自动更新机制。启动后会自动检测服务器上的最新版本，有新版时静默下载并在下次启动时升级。
