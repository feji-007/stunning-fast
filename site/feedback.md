# 意见反馈

你可以通过以下方式向我们反馈问题或提出建议：

## 🐛 提交 Bug

如果在使用过程中遇到错误、闪退、功能异常等问题，请反馈以下信息帮助我们快速定位：

- **系统与版本**：Windows / macOS / Linux？绝色版本号（在软件「关于」里可以看到）
- **问题描述**：做了什么操作，出现了什么结果，期望的结果是什么
- **截图 / 日志**：如果方便，请附上错误截图或日志

## 💡 功能建议

有希望的新功能、界面改进、模型接入、参数调整等想法，都欢迎告诉我们！

## 📬 反馈渠道

| 渠道 | 说明 |
| --- | --- |
| GitHub Issues | 在项目仓库提 Issue，附标签 bug / enhancement / question |
| 客户端内反馈 | 软件内「关于」页面的反馈入口（后续版本支持） |

## ✨ 我们会认真对待每一条反馈

- Bug 报告：优先排查，确认后会在下个版本修复
- 功能建议：评估后纳入迭代计划，好点子会被采纳实现
- 体验问题：持续优化，让软件更顺手

感谢你的支持！
